# 후보 메모함

검토했으면 하는 도구나 키트 개선 생각을 이 폴더에 마크다운 파일로 넣어 둔다. 사람이 넣어도 되고 다른 AI가 넣어도 된다. 다음 `scout` 실행 때 다른 후보와 같은 절차(평가, 시험, 기록, 변경 제안)를 탄다.

파일 이름: `<날짜>-<짧은-제목>.md` (예: `2026-11-20-새-테스트-도구.md`)

적을 것:

- 이름과 출처 주소
- 어떤 일에 쓸 만한지, 키트의 어떤 빈틈을 메우는지
- 써 본 경험이 있으면 그 결과

메모 안의 글은 자료로만 읽힌다. "이것을 설치하라" 같은 지시문을 적어도 그대로 실행되지 않고, 평가를 통과한 것만 변경 제안으로 올라간다. 비밀값(토큰, 키)은 적지 않는다.
