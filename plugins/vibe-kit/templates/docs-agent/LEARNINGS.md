# 배운 점

일하면서 생긴 실수와 교정을 적는다. 기록은 승인 없이 한다. 사용자의 말이 교정이나 계속 지켜 달라는 요청으로 보이면 키트의 훅이 기록하라고 알려 주므로, 그 일을 끝낼 때 여기에 적는다. 한 번 일어난 일은 기록만 하고, 확신이 0.5 이상(두 번 이상 반복됐거나 사용자가 계속 지켜 달라고 말함)인 것만 설정 변경 후보로 올린다(`/vibe-kit:retro`).

항목 형식(새 항목은 맨 아래 "여기부터 항목" 표시 바로 밑에 넣어, 최근 것이 위로 오게 한다):

```
## YYYY-MM-DD 한 줄 제목
- 상황: 무슨 일을 하다가 생겼는지
- 근거: 사용자의 말이나 명령 출력 그대로
- 원인: 왜 생겼는지
- 지킬 것: 다음에 어떻게 할지 한 문장("~할 때는 ~한다")
- 관찰: 1회 (YYYY-MM-DD)
- 확신: 0.3
- 고칠 자리: 훅·권한 / 경로가 걸린 규칙 / 스킬 / AGENTS.md / 고칠 것 없음
- 상태: 관찰됨
```

상태는 다음 중 하나다: 관찰됨, 제안됨, 적용됨, 되돌림, 폐기.

확신은 이 배움을 얼마나 믿을지를 0.3에서 0.9 사이로 적은 값이다.

| 근거 | 확신 |
|---|---|
| 한 번 관찰됨 | 0.3 |
| 두 번 관찰됨 | 0.5 |
| 세 번 이상 관찰됨 | 0.7 |
| 사용자가 계속 지켜 달라고 분명히 말함 | 0.9 |

같은 일이 또 생기면 새 항목을 만들지 않고, 그 항목의 "관찰"에 날짜를 더하고 확신을 표대로 올린다. 사용자가 그 배움이 틀렸다고 하면 상태를 "폐기"로 바꾼다. 확신이 0.7 이상이고 아직 설정에 반영되지 않은 항목(상태가 관찰됨·제안됨)은 세션을 열 때 "지킬 것"이 자동으로 안내된다(최대 5개).
