# 화면 디자인

- 글꼴, 색, 간격은 한 곳({{디자인 값을 모아 둔 파일이나 방식}})에서 정하고, 화면 코드에 값을 직접 쓰지 않는다.
- {{플랫폼}}의 관례를 먼저 따르고 그 위에서 개성을 낸다.
- 뻔한 기본값을 피한다: 어디서나 보이는 글꼴, 흰 바탕의 보라색 그라데이션, 판에 박힌 배치.
- 주색 하나와 뚜렷한 강조색, 개성 있는 글꼴 조합, 깊이 있는 배경, 절제된 움직임을 우선 검토한다.
- 읽기 쉬움과 사용 흐름이 장식보다 먼저다. 둘이 부딪치면 장식을 뺀다.
- {{승인받아 설치한 디자인 도구가 있을 때만 남긴다: 새 화면을 만들 때는 <화면 만들기 도구>로 방향을 먼저 잡고, 끝내기 전에는 <점검·다듬기 도구>로 점검한다. 없으면 이 줄을 지운다}}
- 화면을 바꾼 뒤에는 실제로 띄워 눈으로 확인한다: {{이 프로젝트에서 화면을 띄워 확인하는 방법}}.
