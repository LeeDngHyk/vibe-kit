# 쓰는 사람의 경험

이 파일들은 사람이 직접 마주하는 부분이다. 바꾼 뒤 아래를 확인한다.

- 처음 쓰는 사람이 설명서 없이 첫 동작을 할 수 있는가.
- 오류 안내가 무엇이 잘못됐고 어떻게 고치는지를 쉬운 말로 알려 주는가.
- 기다리는 중, 내용이 없을 때, 실패했을 때의 상태가 각각 준비돼 있는가.
- 같은 것을 같은 낱말로 부르는가. 기본값이 대부분의 사용자에게 맞는가.
- 되돌릴 수 없는 동작 앞에 확인이 있는가.
- 접근성: 글자 크기와 대비가 충분한가. 키보드나 보조 기기로 쓸 수 있는가.
