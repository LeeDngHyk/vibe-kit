# 테스트

- 이름은 "무엇을 하면 무엇이 된다"가 읽히게 짓는다: {{이 프로젝트의 테스트 이름 관례와 예시 하나}}.
- 관련 테스트만 먼저 실행한다: {{파일이나 이름을 지정해 일부만 실행하는 명령}}. 통과하면 전체를 실행한다: {{전체 실행 명령}}.
- 모의 객체(실제 대상 대신 끼워 넣는 가짜)는 네트워크, 시간, 외부 서비스처럼 느리거나 결과가 매번 달라지는 경계에만 쓴다. 이 프로젝트 안의 코드는 실제 것을 쓴다.
- 실패한 테스트는 기대값을 고쳐 통과시키지 않는다. 코드가 틀렸는지 테스트가 틀렸는지 먼저 판단하고, 판단 근거를 보고에 적는다.
