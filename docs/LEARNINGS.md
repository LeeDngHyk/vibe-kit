# 키트가 배운 점

키트를 만들고 고치면서 배운 것을 적는다. 프로젝트에서 올라온 것 중 어느 프로젝트에서나 통하는 것도 여기에 모인다.

항목 형식(새 항목은 맨 아래 "여기부터 항목" 표시 바로 밑에 넣어, 최근 것이 위로 오게 한다):

```
## YYYY-MM-DD 한 줄 제목
- 상황: 무슨 일을 하다가 생겼는지
- 근거: 사용자의 말이나 명령 출력 그대로
- 원인: 왜 생겼는지
- 고칠 자리: 훅·권한 / 스킬 / 서브에이전트 / 템플릿 / 고칠 것 없음
- 상태: 관찰됨
```

상태는 다음 중 하나다: 관찰됨, 제안됨, 적용됨, 되돌림, 폐기.

## 2026-11-16 세션 시작 훅의 "환경 없음" 안내가 무관한 작업의 답에 붙는다
- 상황: 키트 환경이 없는 임시 폴더에서 다른 과제(서버 코드 쓰기, 자동화 추천)를 대화 없이 실행했다.
- 근거: 두 실행의 답 끝에 각각 "이 폴더에는 vibe-kit 환경이 아직 없습니다. 필요하면 `/vibe-kit:setup`을 실행하세요.", "vibe-kit 환경이 필요하면 `/vibe-kit:setup` 한 줄로 만들 수 있습니다"가 붙었다. (같은 날 2회)
- 원인: 훅이 환경 없는 모든 폴더에서 안내를 넣고, 거절을 기억할 방법이 없다. 스크립트나 일회성 폴더에서도 매번 붙는다.
- 고칠 자리: 훅·권한 (`hooks/session-start.js`: 프로젝트처럼 보이는 폴더에서만 안내하거나, 사용자가 환경·설정을 물을 때만 말하도록 문구를 바꾼다)
- 상태: 제안됨
